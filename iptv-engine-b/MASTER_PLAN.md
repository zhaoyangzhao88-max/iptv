# 🛸 IPTV-Engine-B（数据发动机）核心开发总纲

## 一、 项目愿景与核心架构共识
本项目是一个全自动化的 IPTV 数据采集、清洗、测速与重组引擎，旨在为独立的前端播放器（B程序）提供稳定、干净、极速的 `channels.json` 数据源。
项目严格遵守以下 5 大核心架构共识（2026年制定）：
1. **彻底对齐 `iptv-org` 标准**：无"私房菜"，全网抓取的数据必须与 `iptv-org` 的全球字典（分类、Logo、语言）对齐。
2. **零成本云端部署**：抛弃传统云服务器，全架构面向 **GitHub Actions** 自动化流水线设计。
3. **文本级"信誉分"记忆**：抛弃 SQLite，采用纯文本 JSON 记录频道历史拨测分数，与 Git 提交联动，淘汰长期失效烂源。
4. **地方台"按省打包"**：国内地方频道必须根据名称自动映射归类到"浙江频道"、"广东频道"等省级分类中，拒绝大杂烩。
5. **双星架构与黑科技测速**：
   - **Python** 负责高并发 M3U 清洗、硬核 **TS 分片级测速**（提取第一片 TS 下载 10KB）与 **302 广告剥离**（封杀 epg.pw 等假台）。
   - **Node.js** 作为独立前台微服务，专攻 B站、抖音等平台的防盗链 Token 动态解析。
